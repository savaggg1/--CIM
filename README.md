# CIM XML Anonymizer

Проект разработан в рамках хакатона Monitor Electric.

Назначение: автоматизированное обезличивание CIM-моделей в формате RDF/XML и проверка отдельных характеристик обработанной модели.

В архиве `CIM_Project_GitHub_Full.zip` находятся программа обезличивания, вспомогательные скрипты проверки, обезличенная XML-модель и JSON-отчёт. Исходный `input.xml` в архив не включён.

Для запуска требуется Python 3.11 и библиотека lxml. Список зависимостей находится в `requirements.txt` внутри архива.
