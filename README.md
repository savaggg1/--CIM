# CIM XML Anonymizer

## Описание проекта

Проект разработан в рамках хакатона Monitor Electric.

Цель проекта — разработка программы для автоматизированного обезличивания моделей CIM, представленных в формате RDF/XML, с сохранением структуры модели и связей между объектами.

## Основные возможности

- Обработка CIM-моделей в формате XML.
- Обезличивание идентификаторов и названий объектов.
- Обработка чувствительных текстовых полей.
- Сохранение структуры XML.
- Формирование отчёта о результатах обработки.
- Проверка целостности ссылок между объектами.

## Описание файлов

| Файл | Назначение |
|---|---|
| `anonymize_cim.py` | Основной скрипт обезличивания CIM/XML |
| `compare_xml.py` | Сравнение количества объектов и ссылок в исходной и обработанной моделях |
| `check_references.py` | Проверка внутренних ссылок между объектами |
| `check_sensitive.py` | Проверка изменения выбранных чувствительных текстовых полей |
| `check_structure.py` | Сравнение распределения типов объектов и проверка дубликатов |
| `output_anonymized.xml` | Результат обработки (большой файл, для GitHub используется Git LFS) |
| `output_anonymized.xml.report.json` | Отчёт со статистикой обезличивания |
| `requirements.txt` | Список необходимых Python-библиотек |

Дополнительные проверки:

- Количество RDF-ссылок совпадает.

- Распределение по 263 типам объектов совпадает.
- Дубликаты идентификаторов не обнаружены.
- XML успешно прошёл проверку корректности.

## Используемые технологии

- Python 3.11
- lxml
- RDF/XML
- CIM

## Запуск программы

Установка зависимости:

```bash
python -m pip install -r requirements.txt
```

Запуск обезличивания:

```bash
python anonymize_cim.py input.xml output_anonymized.xml
```

Запуск проверок:

```bash
python compare_xml.py
python check_references.py
python check_sensitive.py
python check_structure.py
```
